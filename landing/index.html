One command per mile-marker

Your build is still your job (Xcode / altool). Shipside takes the last mile — and tells you exactly what it can't do for you.

commandwhat it doeswrites?
shipside initConfig wizard — bundle id, your ASC API key (referenced by path, never uploaded), review contact → shipside.tomllocal file
shipside stateFull ASC status report: versions, builds, screenshots, IAPs, review submissions + the next actionno
shipside planThe submission dry-run: every step marked ok / fix / blocked, nothing writtenno
shipside metadataPush listing text (fastlane-deliver-compatible folders) into the editable version, char limits enforcedyes
shipside screenshotsUpload 1320×2868 / 1290×2796 PNGs into the 6.7″ set — enum trap handledyes
shipside submit --yesCreates the version (two API routes, 405 playbook), sets age rating + review details, attaches the newest VALID build, submits for reviewirreversible

retry with a spine

429/5xx back off respecting Retry-After; a 409 on a retried write means the first one landed — treated as success.

your keys, your machine

The .p8 is referenced by path and stays put. Shipside's servers never see your ASC credentials — the license check is separate.
